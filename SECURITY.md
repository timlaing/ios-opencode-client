# Security reports

Do not report vulnerabilities, credentials, pairing tokens or private conversation
content in public issues or pull requests.

Use [GitHub private vulnerability reporting](https://github.com/timlaing/ios-opencode-client/security/advisories/new)
when the repository offers “Report a vulnerability”. If that option is unavailable,
contact the maintainer through the contact details on their
[GitHub profile](https://github.com/timlaing) to arrange a private channel before
sharing sensitive details.

Include the affected app/plugin/server versions, impact and a minimal reproduction.
Use synthetic data and redact logs. Supported releases and response timelines will
be documented when the app is released; no response-time guarantee is currently made.
